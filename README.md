# Fortisec Inndos Website
A static marketing website for Fortisec Inndos - a software development company based in Nairobi, Kenya.
## Structure
├── about.html
├── assets
│   └── images
│       └── logo.png
├── contact.html
├── css
│   └── styles.css
├── index.html
├── projects.html
├── README.md
├── robots.txt
├── services
│   ├── index.html
│   ├── mobile-development.html
│   ├── software-development.html
│   └── web-development.html
└── sitemap.xml
## Pages
Home(`index.html`) - Hero, services overview, what we build, recent projects, how we work
Services (`services/index.html`) - Overview of three main services (Web, Software, Mobile)
web Development (`services/web-development.html`) - Details and example projects
Software Development (`services/software-development.html`) - Details and example projects
Mobile Development(`services/mobile-development.html`) - Details and example projects
Projects(`projects.html`) - All example projects organized by service
About(`about.html`) - Company information and process
Contact*(`contact.html`) - Contact form and information
## Launch
Open `index.html` in a web browser to view the site.
